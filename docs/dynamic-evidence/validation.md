## 指标口径

- 终局正确率以每次运行的预期资格结果为分母。合理升级、过度弃答和自动正确完成另外列计数。
- 关键条件召回使用独立预期中的阈值/工单条件，按条件值匹配。被接纳关系错误比例以已接纳关系为分母。
- 动态路径成功要求初图无工单义务、合同来源可查、新条件入图、查询由新缺口触发、最终输出有依据且版本一致。固定全查即使得出正确结论也不计动态路径成功。
- 无依据率以确定回答为分母，核对当次回执、独立预期与证据引用。普通 Prompt 的引用一致性采用独立必要记录清单，未做额外模型裁判。
- 版本一致性比较任务、运行、图、答案四个版本键。引用可解析率按来源记录 ID 与真实调用回执回查。不能解析和分母为零分别记录。
- 模拟故障分层统计。真实模型自然异常保留原始输出和停止原因，不能当作注入故障或跳过。未观察到的费用不填零。
